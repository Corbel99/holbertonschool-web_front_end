# Advanced CSS

This repository contains the **Advanced CSS** project for Holberton School.

## Project overview

The goal is to practice advanced CSS concepts by styling the Techium website, following the project instructions and reference screenshots.

Topics covered include:

- CSS selectors, properties, values, and specificity
- The box model, spacing, positioning, and overflow
- CSS variables and reusable styles
- Typography, font sizes, and web fonts
- Pseudo-classes and pseudo-elements
- Gradients, transitions, animations, and transforms
- Layout techniques and responsive design foundations

## Image assets

The `images/` directory contains the ten image assets used by the project tasks. Use high-resolution images that match the category of each file (about, work, article, or person). The project instructions also require the supplied `favicon.jpg`, `logo-black.png`, and `logo-white.png` assets to be added to `images/` when needed.

## Requirements

- Use the requested filenames exactly; capitalization and spelling matter.
- Keep all project files ending with a newline.
- Add a comment describing the task at the beginning of each task file, as requested by the project.
- Validate the HTML and CSS with the W3C validators.
- Check the rendered result in the browser against the project reference.
