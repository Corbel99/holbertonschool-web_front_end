# Advanced HTML

## Description

This project focuses on the structure and semantics of HTML documents. It introduces the elements used to organize web pages and represent different types of content.

The project uses **Techium** as the company name for the website content.

## Learning Objectives

- Understand the structure of an HTML document.
- Use headings and paragraphs to organize content.
- Apply semantic HTML elements.
- Create links and lists.
- Embed images, videos, audio, and external content.
- Structure tabular data using HTML tables.
- Understand HTML attributes and their purpose.
- Validate HTML documents according to web standards.

## Requirements

- Use HTML only.
- Do not use CSS or styling.
- Follow the project instructions and HTML syntax rules.
- Validate HTML files using the W3C Validator.
- Include a sitemap and follow the provided homepage wireframe where required.
